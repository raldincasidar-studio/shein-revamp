# API Documentation: frogleo/AI-Clothes-Changer

Use the `gradio_client` Python library or the `@gradio/client` JavaScript package to query the app via API.

## Setup

Install the client if you don't already have it installed:

```bash
npm i -D @gradio/client

```

### Parameters
